# Hemin & Nikhyta wedding website

## Upload to GitHub

1. Extract the ZIP file.
2. Open the `heminD77/hem-weds-nik` repository on GitHub.
3. Upload the **contents** of this folder to the repository root, preserving the `wedding-assets` folder.
4. Replace the existing files when prompted and commit the upload.

GitHub Pages should be configured to deploy from the `main` branch and the repository root.

Required structure:

```text
/
├── .nojekyll
├── index.html
└── wedding-assets/
    ├── couple.webp
    ├── favicon.svg
    ├── fonts.css
    └── venue.webp
```

Do not use the browser's **Save page as** command; it rewrites the website's relative paths.
